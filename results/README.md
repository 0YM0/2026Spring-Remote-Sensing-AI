# Archived results

This directory contains lightweight outputs retained for transparent inspection of the reported experiments.

- `experiments/`: per-run training logs, summaries, classification reports, and confusion matrices.
- `analysis/`: derived tables and figures comparing models, classes, and ablation variants.

Model checkpoints, graph caches, full-resolution prediction rasters, and web-map tile caches are excluded because they are generated and/or too large for a source repository.
